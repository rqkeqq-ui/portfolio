# rqke / SYSTEMS

Статическое портфолио независимого разработчика для бизнеса: HTML, CSS, Vanilla JavaScript и Vite.

## Запуск

```sh
npm ci
npm run dev
```

Dev: http://localhost:5173/. Сборка: `npm run build`; просмотр сборки: `npm run preview`.

## Содержание

Главная: задачи клиентов, работы, состав услуги, процесс, стоимость, FAQ и контакт. Архив и два личных проекта с реализованными сценариями и ограничениями. RU/EN, адаптивная навигация, лента работ на десктопе и вертикальные карточки на мобильном.

Необязательный бриф готовит сообщение, позволяет скопировать его и открыть Telegram. Сайт самостоятельно ничего не отправляет. Cal.com с Google Meet загружается после нажатия «Выбрать время созвона»; предусмотрены внешняя ссылка и Telegram.

## Данные и стили

`assets/js/data.js` — проекты, ссылки и запись. `assets/js/home-copy.js` — RU/EN тексты. `assets/js/core.js` — общий интерфейс и язык.

Главная подключает `assets/css/experience.css`, который импортирует global, home и revision в этом порядке, сохраняя порядок стилей при сборке.

## Запись

30 минут, ежедневно 13:00–20:00 UTC+7. Cal.com: окно 14 дней, минимум за 24 часа, перерыв 15 минут, до 3 встреч в день, проверка занятости Google Календаря. Google Meet выбран местом проведения. Посетитель выбирает часовой пояс и формат 12/24 часа в интерфейсе записи; начальный формат зависит от настроек браузера.

Для замены встречи обновите bookingUrl и calLink в data.js. Модуль booking.js использует официальный Cal.com embed, тёмную тему и месячный вид. Скрипт и iframe отсутствуют до первого открытия.

Footer удалён. На десктопе прокрутка страницы фиксирует секцию работ и двигает карточки с индикатором прогресса. При reduced motion, коротком экране и увеличении текста карточки показываются без фиксации, чтобы всё содержимое оставалось доступным.

## Публикация

GitHub Actions собирает и публикует dist после push в main: https://rqkeqq-ui.github.io/portfolio/. Относительный Vite base поддерживает вложенные страницы.

Перед push в main получить одобрение владельца после локального просмотра: push запускает публикацию автоматически.

События доступны как `rqke:analytics` CustomEvent с именем в `detail.name`. Провайдер не подключён; данные брифа не передаются. Загрузка iframe не считается записью.

Проверки: [docs/website-revision-validation.md](docs/website-revision-validation.md).
